# claude-mod-status-bar

Shows profile, model, usage bars and context under the prompt, in the terminal and the desktop app. Measures with PowerShell (Windows) rather than bash.

## Install

```bash
claude plugin marketplace add smhasan-yad/claude-mod-status-bar
claude plugin install status-bar@claude-mod-status-bar
```

A new chat or /reload-plugins picks it up. Written for the Windows desktop app and terminal (Claude Code mods API); not tested elsewhere.
